# 日本語 STT 評価 — 実測記録（historical measurements）

このリポジトリの STT ハーネスで 2026-09-16 に取得した測定の記録。すべて **historical measurement** として読む。

- 環境は [environment.md](environment.md)。音源・manifest・録音・生ログはリポジトリに含めないため、
  同じ数値をこのリポジトリだけで再現することはできない。
- 当時のコードと現在のコードは、モジュール名・整形・表示文言以外の計測ロジックを変えていないが、
  旧履歴を引き継いでいないため、同一性を機械的に検証したものではない。
- 合成音声 40 文（`tts_normal`）は当時ローカル TTS で作った短い質問文で、このリポジトリの
  `fixtures/test-plan.json` とは別の文。自然発話の録音のガイド文も、公開用の
  `fixtures/natural-speech-prompts.json` とは語を置き換えている。
- 指標の定義は [methodology.md](methodology.md)。

## Series A — 同一入力 160 件の比較と 65 分継続

構成: Windows Python / WASAPI、hosted `gpt-live-transcribe`（medium、日本語、hint なし）、
WSL NeMo 3.0.0 / Parakeet JA（FP32 / TDT、0.5 秒以上ごとの prefix 再推論）。両方式へ同時投入。
各音源の最初の試行だけで品質を集計し、65 分試験の反復は独立標本にしない。CER はサンプル平均、
語彙は micro 平均。T0 は発話全体の投入開始で、キーワードが発話されるまでの時間を含む。

### 65 分継続

- STT 実時間 3910.3 秒、判定 PASS。372 試行 × 2 方式の 744 結果が全件成功。
- 最終 partial の到着経過秒: hosted 3906.8、parakeet 3909.7。
- hosted 接続 2 回、計画切替 1 回（55 分を超えた発話境界）。切替時刻付近で最大キュー滞留 3544.7 ms
  （parakeet は 17.2 ms）。低遅延の完全な切替とは評価しない。
- 同一入力の再試行で初回と final が正規化一致: hosted 149/212、parakeet 212/212。初回からの平均 CER 変化はともに 0.0 ポイント。
- 音声は 20 ms ごとの実時間投入。各発話に 1 秒の末尾無音を付け、final 待ち後に次を開始。途切れのない生会議の代替ではない。

### 取得系の耐久（WASAPI ＋ マイク、無音 render 維持、61 分）

- 3660 秒。フレーム時間の被覆率: loopback 1.0000109、microphone 1.0。
- loopback frames=175681920、microphone frames=175680000（48 kHz）。両入力と render の status flag、
  キュードロップ、取得エラーはすべて 0。
- 別の通常 65 分取得（無音 render なし）では無再生時に loopback 通知が止まり、マイク約 65 分に対して
  loopback 約 49.5 分のフレームだった。これは連続取得の証明から除外し、音声ドロップとも断定しない。

### 実経路 smoke（既定出力で fixture を再生 → WASAPI → Parakeet）

成功。正しい判定語を含む partial 3 回、final 1 回。最初の該当 partial は再生 API 呼出から 1365.6 ms。
fixture 直接投入の T0 とは基準が異なる。認識文字列・取得音声は保存していない。

### 費用

hosted 単価は公式確認済み USD 0.017 / 音声分（2026-09-16）。60 分の連続音声は推定 USD 1.02。
送信量に基づく推定であり請求実額ではない。ローカル推論に API 従量課金はなく、電力・機器費用は未計測。

### Series A の判断範囲

通常実声では重要語回収率が同率で、Parakeet の CER と到着速度が良かった。人工雑音条件では重要語回収率にも
差があった。high は medium より雑音付き CER が低かったが、重要語回収率で優位にならなかった。
自然な小声・ボソボソ・早口・言い淀み、実会議 codec、実アプリ併用の負荷は Series A では未計測。

## Series B — 自然発話・会議経路・prefix 間隔比較

### 実会議経路（500 ms、live）

別端末から話した音声を、受信 PC の WASAPI から Parakeet へリアルタイムで渡し、同じ音声の SHA を保存 WAV と
照合した。会議サービスの codec・音声処理設定は記録できていない。受信 PC での取得以降を測っており、
遠端マイクからのネットワーク遅延は含まない。
